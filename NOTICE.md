# Asal source dan aset

Proyek ini melanjutkan folder `rental-car` milik workspace pengguna. Source awal memiliki beranda, katalog `produk.html`, keranjang `cart.html`, serta enam mobil dalam `data.json`. Folder tersebut membawa remote/riwayat dari `kopikuyweb`; repo rental dibuat terpisah agar tidak menimpa website kopi.

Perapihan mempertahankan logo Sewa Mobil, arah cokelat/cream, enam mobil, tarif awal, pemilihan, hari sewa, keranjang, dan rumus tambahan 10%. Harga menjadi bilangan integer, jumlah unit dihitung eksplisit, serta keranjang tidak lagi tertimpa ketika kembali ke katalog. Tata letak, modul DOM, validasi, pemulihan penyimpanan, tema dan unduhan ditulis ulang untuk alur demo yang dapat dicoba.

Logo `images/rental.png`, foto `images/RENTAL-MOBIL.jpg` dan enam foto dalam `images/Product/` disalin tanpa mengubah isi dari proyek awal. Sumber/lisensi pencipta gambar tidak tercantum pada source awal; gambar tersebut bukan diklaim sebagai karya baru pembuat perapihan. Tinjau hak pemakaian sebelum menggunakan ulang untuk layanan komersial. Merek/model kendaraan hanya mengidentifikasi contoh katalog.

Testimoni, foto pelanggan, nomor kontak, dan peta dari prototipe awal tidak memiliki bukti sebagai layanan aktif. Bagian tersebut digantikan penjelasan estimasi dan unduhan lokal. Aplikasi tidak mengirim pesan kepada nomor pribadi. Font dan library Bootstrap/jQuery lama yang tidak lagi dipakai tidak dibundel; UI memakai font sistem dan JavaScript bawaan browser.

Source asli dan riwayat Git tetap tersimpan terpisah. Dokumen ini mencatat asal dan perubahan; tidak menetapkan lisensi baru untuk source atau gambar pengguna.
